# 🎬 Studio Ghibli Explorer
An interactive website for exploring Studio Ghibli movies using an external API.

## ✨ Features
- Browse Studio Ghibli movies
- Explore movie information
- Display movie posters and details
- Fetch movie data from an API

## 🛠️ Technologies
HTML • CSS • JavaScript • REST API
